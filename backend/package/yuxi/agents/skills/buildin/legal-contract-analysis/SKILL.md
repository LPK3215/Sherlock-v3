# 合同和协议分析

这是夏洛克的合同分析能力,不是独立法律 Agent,也不替代律师审查。

## 流程

1. 读取用户提供的合同文本、图片或文档;扫描件看不清时先使用 OCR 或要求补充清晰文件。
2. 先列出文档类型、当事人、期限、金额、履行事项和缺失信息,不猜测未提供内容。
3. 按条款定位解释权利义务,重点检查付款、交付、违约、免责、自动续约、单方变更、保密、知识产权、争议解决和退出机制。
4. 对每个风险给出原文位置、通俗解释、可能影响、需要核实的事实和风险等级;风险等级是辅助判断,不是确定法律结论。
5. 只有用户要求法律依据或材料来自已配置知识库时,才调用知识库工具并保留来源信息。
6. 普通合同分析不保存数据库;用户明确要求保存时交由法律事务总 Skill 按确认流程处理。

## 输出结构

文档概况、关键条款、权利义务、可能风险、缺失信息、建议核实事项、专业咨询提示。
