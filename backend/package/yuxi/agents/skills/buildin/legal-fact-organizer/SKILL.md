# 法律事实整理

这是夏洛克的材料整理能力,只整理已提供内容,不替用户裁判事实真伪。

## 流程

1. 分别标注用户陈述、文件原文、图片或记录中的内容、推测和待核实事项。
2. 按日期和时间建立事件时间线,无法确定的时间保留不确定标记。
3. 建立证据清单,包含来源文件、可证明的内容、缺口和关联事件。
4. 列出需要用户补充的合同、通知、付款、沟通记录或其他材料。
5. 不把事实整理自动保存为法律事务;只有用户明确要求并确认后,交由总 Skill 调用记录工具。

## 输出结构

已知材料、事件时间线、证据清单、事实缺口、待核实问题和下一步整理建议。
