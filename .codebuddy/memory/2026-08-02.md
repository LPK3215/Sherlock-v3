## Cascade 模式实现（2026-08-02）

### 文件结构

```
server/
├── bot.py              # 启动器（读 AI_MODE，委托到 realtime 或 cascade）
├── bot_realtime.py     # Realtime 模式（原 bot.py，保留不动）
├── bot_cascade.py      # Cascade 模式（STT + VLM + TTS，新建）
├── .env                # 环境变量（含两种模式的配置）
├── env.example         # 环境变量模板
├── run.ps1             # 启动脚本（更新：加 PYTHONPATH）
└── pyproject.toml      # 依赖（加 openai extra）
```

### bot.py 启动器逻辑

```
AI_MODE=realtime → from bot_realtime import run_bot → Gemini Live S2S
AI_MODE=cascade  → from bot_cascade import run_bot_cascade → STT+VLM+TTS
```

### bot_cascade.py Pipeline

```
transport.input → OpenAISTTService → user_aggregator(VAD) → OpenAILLMService → OpenAITTSService → transport.output → assistant_aggregator
```

特点：
- 三阶段独立配置（CASCADE_STT_*/CASCADE_VLM_*/CASCADE_TTS_*）
- 支持任意 OpenAI 兼容 API（魔搭/OpenAI/自定义）
- 内置 fetch_camera_image / fetch_screen_image 视觉工具
- 使用 Pipecat 1.7 API（PipelineWorker + LLMContext + LLMContextAggregatorPair）

### 零成本 Cascade 方案（用户需自行获取 Key）

```
STT: CASCADE_STT_BASE_URL + CASCADE_STT_API_KEY  (OpenAI Whisper 或兼容)
VLM: CASCADE_VLM_BASE_URL=https://api-inference.modelscope.cn/v1  (魔搭 Qwen-VL)
TTS: CASCADE_TTS_BASE_URL + CASCADE_TTS_API_KEY  (OpenAI TTS 或兼容)
```

### 测试结果

- ✅ `bot_cascade.py` 导入无错误
- ✅ `AI_MODE=cascade` 启动成功（Uvicorn on :7860）
- ⚠️ 实际 API 调用需用户填入 CASCADE_*_API_KEY 后才可测试

### Pipecat 1.7 API 适配注意事项

| 旧 API | Pipecat 1.7 |
|--------|-------------|
| `OpenAILLMContext` | `LLMContext` |

## Cascade 三件套全切换重构（2026-08-02）

### 需求
用户要求 STT、VLM、TTS 每个组件都支持多种 provider 切换，而不是绑定单一方案。

### 最终支持矩阵

```
STT provider:  whisper | funasr | moonshine | openai
VLM provider:  minicpm | openai
TTS provider:  kokoro | piper | openai
```

默认组合（零成本，全免费）：
- STT: whisper (tiny, auto device) — 本地 Faster Whisper
- VLM: minicpm (MiniCPM-O-4.5-9B) — 免费公钥 `sk-live-kmwPsO1yz9kJfbp8c6az72I-BjfZBX-5V5CmI9yTsXw`
- TTS: kokoro (af_sky voice) — 本地 ONNX

### 技术实现

1. **懒加载**：`bot_cascade.py` 不再在顶部 eager import 所有 provider 的 Service 类（funasr/kokoro/piper/moonshine/whisper），改用 `_lazy()` 函数按需加载。效果：即使某个 provider 的依赖（如 torchaudio for funasr）未安装，只要不用该 provider 就不会 crash。

2. **依赖安装**：
   - `pyproject.toml` extras 加 `funasr,kokoro,moonshine,piper,pocket-tts`
   - 额外 `uv pip install torchaudio`（funasr 隐式依赖，Pipecat extra 未声明）
   - `uv sync` 新增 71 个包（含 torch 116MB、piper-tts 32MB、transformers 11MB 等）

3. **配置方式**：每个组件通过 `CASCADE_<STAGE>_PROVIDER=<name>` 选择，然后读 `<STAGE>_<PROVIDER>_*` 环境变量

### API Key 需求总结（用户视角）

| 组件 | 可选 provider | 需要 Key？ | 用户现有的 |
|------|------|:---:|:---:|
