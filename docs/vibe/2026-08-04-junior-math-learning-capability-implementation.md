# 初中数学学习助手能力包阶段总结

## 目标

在 Yuxi 现有 Agent、知识库、多模态实时会话、Skill 和 Tool 架构上,落地第一个可验证的夏洛克业务能力包。首版选择初中数学学习助手,验证从题目输入到讲解、错题保存和历史查询的最小闭环。

## 已实现

- 新增 `junior-math-learning` 内置 Skill,声明初中数学讲题、知识库检索和错题整理流程。
- Skill 依赖现有 `knowledge-base` Skill,复用 `query_kb` 和 `open_kb_document` 等 Yuxi 原生知识库工具。
- 新增 `learning` 工具分类和四个原生 Tool:保存、查询、更新、删除错题。
- 新增 `learning_wrong_questions` 业务表和 `LearningRepository`。
- 所有错题查询、更新和删除均带当前用户 UID 条件,避免跨用户访问。
- 更新和删除在 Skill 规则中要求用户明确确认。
- 实时摄像头、共享屏幕、图片、文档、语音和文字继续复用现有 Yuxi 输入链路。

## 当前边界

- 已接入知识库能力依赖,尚未导入真实教材、章节资料或题库内容。
- 当前业务数据只覆盖错题记录,学生档案、学习计划、知识点掌握统计和学习事件将在后续阶段设计。
- 已验证 Tool 注册、参数校验、UID 传递、Skill 依赖和 Python 编译;真实浏览器业务流程尚未完成 E2E 验收。
- 模型负责题目理解和讲解,本阶段没有新增独立数学判题规则引擎。

## 下一阶段

1. 导入一套明确版本的初中数学教材和题库,建立年级、章节、知识点元数据边界。
2. 增加学生档案和知识点掌握记录,再设计学习计划和学习事件。
3. 用真实用户端完成拍题、实时视频讲题、语音追问、保存错题和历史查询 E2E。
4. 完成首个闭环验收后,再评估第二个学科或领域能力包。
