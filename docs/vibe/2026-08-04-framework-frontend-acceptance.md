# Yuxi 框架前端验收记录

## 范围

`web` 是 Yuxi 官方管理/框架前端,继续保留官方 Agent 管理、模型管理、Tools、Skills、MCP、知识库和普通文字聊天能力。本阶段不修改其基础业务,只确认实时后端接入没有破坏它。

## 当前结论

| 项目 | 结果 | 说明 |
|---|---|---|
| 框架前端仍可独立部署 | 通过 | Compose `web` 服务运行,共享唯一 `api` |
| 官方登录/Agent 管理/模型管理 | 保留 | 本项目不重复验收官方基础功能 |
| 官方普通聊天 | 保留 | 未被实时模块替换或删除 |
| 与实时后端共存 | 通过 | 两者调用同一个 Yuxi API |
| 框架前端内嵌实时入口 | 未实现 | 这是第四阶段设计任务,不属于当前双前端验收 |

## 当前边界

当前成品是“一套 Yuxi 后端 + 两套前端”:框架管理前端负责官方管理与普通聊天,`user-app` 负责实时语音/视频/屏幕交互。两者共享认证、Agent、模型和 AgentRun 数据。

## 第四阶段候选方案

在 `web` 的聊天页面增加“开启实时通话”入口,跳转或弹出 `user-app` 实时路由;实时媒体仍由 `user-app` 和 `/api/realtime/*` 处理,不复制后端。实施前需要单独确认 UI 形态、权限和跨前端会话体验。
