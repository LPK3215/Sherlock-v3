Sherlock-v3

基于 Pipecat 的 AI 实时语音对话系统，支持摄像头、屏幕共享和可拖拽布局

v1.0.0 · SmallWebRTC · Cascade 管线

项目简介

🎯

核心价值

基于 Pipecat 框架构建的 AI 实时语音对话系统，采用 SmallWebRTC 传输方式，无需 Daily API Key，使用 Cascade 管线模式实现低延迟语音对话。

💡

核心能力

  • 实时语音对话（STT → VLM → TTS）
  • 摄像头视频输入
  • 屏幕共享
  • 可拖拽界面布局
  • 事件日志面板

架构全景

技术栈

后端

Python Pipecat SmallWebRTC

AI 模型

Whisper (STT) OpenAI 兼容 (VLM) Piper (TTS)

前端

Next.js 15 Tailwind CSS v4 Voice UI Kit

快速开始

1

安装依赖

bash

pip install -r requirements.txt
cd src && npm install
2

启动开发服务器

bash
npm run dev
