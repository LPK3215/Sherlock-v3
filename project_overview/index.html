03 / RUNTIME FLOW

一次对话,穿过哪些边界?

01Collect

前端收集文本、附件和智能体配置。

→
02Route

API 路由进入 chat service 与 agent run。

→
03Execute

worker 执行 LangGraph,按需挂载工具。

→
04Deliver

Redis 事件、Postgres 状态和产物回到前端。

01Connect

通过 /api/realtime 完成 WebRTC 协商。

→
02Perceive

Pipecat 处理语音、视频帧、屏幕与文字。

→
03Run

媒体输入进入标准 AgentRun 与 worker。

→
04Respond

事件回到实时管线,再由 TTS 交付。
